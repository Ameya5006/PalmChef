# PalmChef — The Hands-Free Kitchen Assistant

Gesture-controlled cooking assistant with MediaPipe hand tracking, TTS guidance, smart timers, PDF parsing, offline PWA, and a modern React + TypeScript stack.

## ✨ Features
- Upload or link recipes (PDF / URL)
- Real-time hand gestures (✋ Next, ✊ Previous, ✌️ Repeat, 👍 Start/Pause timer)
- Text-to-Speech narration with adjustable rate/pitch
- Auto-detect durations like “bake for 15 minutes” and start timers
- Offline-ready PWA + installable
- Zustand state + localStorage persistence
- Tailwind + Framer Motion UI, light/dark themes
- Unit tests with Vitest + React Testing Library
